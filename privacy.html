Privacy Policy

stream-clipper — last updated 22 November 2026

Summary

stream-clipper is a personal tool run by one person on their own computer. It has no users other than its operator, no server, and no database. It does not collect information from anybody.

What the app accesses

The app requests a single Google permission, https://www.googleapis.com/auth/youtube.upload. This allows it to upload videos to the operator's own YouTube channel. It does not permit reading, editing or deleting anything on the account, and the app does not request any other scope.

What is stored, and where

  • An OAuth refresh token, written to a file on the operator's own computer, so the tool can upload without signing in each time. It is not transmitted anywhere except to Google when refreshing access.
  • Video files and their titles and descriptions, on the same computer, until they are uploaded.

Nothing is stored on any server, because there is no server. Nothing is shared with any third party.

What is sent to Google

Only the video file and its title, description and tags, when the operator's own tool publishes a clip to the operator's own channel.

What is sent elsewhere

The tool sends the text of a clip's transcript to the Anthropic API to draft a title and description. No video, no account information and no personal data are sent. This step can be switched off, in which case nothing leaves the computer except the upload to YouTube.

Analytics and tracking

There are none. This site sets no cookies and runs no scripts.

Removing access

Access can be revoked at any time from Google Account permissions, which immediately invalidates the stored token.

Contact

Questions about this policy can be sent to the support address listed on the Google consent screen for this application.
